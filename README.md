# Astronomy — навчальні скрипти з астрономії

Колекція Python-скриптів для роботи зі зображеннями галактик і Сонця. Це окремі дослідницькі утиліти, а не один спільний додаток.

## Що міститься в репозиторії

| Файл | Призначення |
| --- | --- |
| `galaxy.py` | Збирання зображень галактик із визначеної Google-форми за допомогою Selenium та Beautiful Soup. Зображення зберігаються в `galaxy_images/`. |
| `classification.py` | Сортування зображень галактик за морфологічними типами з використанням SIMBAD; формує папки за типами та `classification_report.csv`. |
| `wolf.py` | Попередня оцінка числа Вольфа за знімками Сонця: пошук темних плям, групування DBSCAN, таблиця `wolf_numbers.csv` і графік зміни числа Вольфа. |

## Підготовка

Потрібен Python 3.10+ та бібліотеки:

```bash
python -m pip install astroquery selenium webdriver-manager requests beautifulsoup4 opencv-python numpy pandas scikit-learn matplotlib pillow
```

Для `galaxy.py` також потрібен Google Chrome і доступ до сторінки-джерела. Для запитів SIMBAD у `classification.py` необхідне інтернет-з'єднання.

## Запуск

Скрипти запускаються окремо:

```bash
python galaxy.py
python classification.py
python wolf.py
```

**Перед запуском відредагуйте шляхи в коді:**
- `classification.py`: `INPUT_PATH` і `OUTPUT_DIR`;
- `wolf.py`: змінну `folder`;
- `galaxy.py`: `FORM_URL`, якщо потрібно використовувати інше джерело, і `OUT_DIR`.

Поточні версії деяких скриптів містять локальні Windows-шляхи автора; вони не працюватимуть на іншому комп'ютері без заміни.

## Примітки до методики

У `wolf.py` число Вольфа визначається як `W = k(10g + s)`, де `g` — число автоматично виділених груп плям, `s` — число знайдених плям, `k = 1` за замовчуванням. Результат залежить від якості зображення, порога сегментації та параметрів групування; це автоматизована оцінка, яку варто звіряти з ручним підрахунком.

Морфологічні типи галактик беруться із SIMBAD, а не визначаються моделлю за формою зображення. Невідомі типи потрапляють до `Unknown`.
